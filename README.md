## About

A **smooth image slider** with navigation arrows, dot indicators, auto-play functionality, and swipe support. Perfect for hero sections, galleries, and showcases.

Built with **vanilla HTML, CSS, and JavaScript** -- lightweight and smooth.

---

## Features

| Feature | Description |
|---------|-------------|
| Navigation Arrows | Previous and next buttons |
| Dot Indicators | Click to jump to slide |
| Auto-Play | Slides automatically |
| Smooth Transitions | CSS transition animations |
| Responsive | Works on all devices |
| Infinite Loop | Continuous sliding |
| Touch Support | Swipe on mobile |
| Pause on Hover | Stops auto-play on hover |
